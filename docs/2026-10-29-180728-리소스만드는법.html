1ChatGPT로 그림 만들기

Tripo는 그림 한 장(또는 정면·측면·뒷면)으로 3D를 만듭니다. 그림이 깔끔할수록 결과가 좋습니다. 아래 프롬프트를 그대로 복사해 쓰세요. 영어가 이미지 생성에 더 정확해서 영어로 적었습니다.

그림 규칙

  • 흰 배경 하나, 그림자 없음, 바닥 없음
  • 정면에서 똑바로(원근 없음), 부품 하나만
  • 단색 면 위주(로우폴리 장난감 느낌), 잔무늬 없음
  • 몸통 그림에는 얼굴과 투구를 빼고 그리기

1-1. 콘셉트 (전체 모습 확인용)

A cute chubby knight character in the style of Overcooked: one round bean-shaped body where head and torso are a single piece, no legs, no arms, two floating round mitten hands beside the body, a simple knight helmet with a small plume, toy-like low poly look with flat solid colors, soft rounded edges. Front view, orthographic, centered, plain white background, no shadow, no floor, full body visible.

마음에 드는 콘셉트가 나오면 그 그림을 첨부한 채로 아래 1-2~1-5를 요청하면 같은 캐릭터로 맞춰집니다.

1-2. 몸통 (얼굴, 투구 없이)

Using the attached character as reference, draw ONLY the body: the single bean-shaped head-and-torso piece, with NO helmet, NO face (leave the face area as a smooth blank skin-colored surface), NO hands. Keep the same colors and clothing details. Show three orthographic views side by side: front, side, back. Plain white background, no shadow, flat solid colors, toy-like low poly style.

1-3. 투구

Using the attached character as reference, draw ONLY the knight helmet as a separate object, empty inside, no head. Same colors and style. Three orthographic views side by side: front, side, back. Plain white background, no shadow, flat solid colors, toy-like low poly style.

1-4. 손

A single round cartoon mitten hand (like Overcooked characters), closed fist slightly open so it could hold a stick, matching the attached character's glove color. Front and side orthographic views. Plain white background, no shadow, flat solid colors, toy-like low poly style.

1-5. 얼굴 표정 3장

A face expression sheet for the attached cute character, drawn as flat 2D cartoon facial features only (eyes, eyebrows, mouth, small blush), no head outline, no skin, on a transparent background. Three separate expressions in a row, each centered in its own square: 1) idle - calm happy, 2) hit - eyes squeezed shut with a pained open mouth, 3) dead - X X eyes with a wavy mouth. Thick clean outlines, bold simple shapes that read well when small.

받은 그림을 세 칸으로 잘라 T_Face_Idle.png, T_Face_Hit.png, T_Face_Dead.png로 저장합니다(각 512×512, 투명 배경). 투명 배경이 안 나오면 흰 배경도 괜찮습니다. 제가 처리하겠습니다.

2Tripo로 3D 만들기

  1. Image to 3D를 고릅니다. 정면·측면·뒷면 그림이 있으면 Multi-view로 세 장을 넣습니다(정확도가 크게 올라갑니다).
  2. 부품마다 따로 생성합니다: 몸통, 투구, 손. 한 번에 만들면 Blender에서 잘라야 해서 일이 많아집니다.
  3. 옵션
    • 메시: Low Poly / Smart Low Poly(있으면), 또는 생성 후 Retopology(Quad, 낮은 면 수)
    • 텍스처: 켬(기본 색만 있으면 됨). PBR(금속성/거칠기)은 필요 없음
    • 스타일 변환 옵션은 쓰지 않음
  4. 결과를 돌려 보며 확인: 뒷면이 뭉개지지 않았는지, 바닥이 뚫리지 않았는지. 이상하면 다시 생성합니다(무료 크레딧이 허락하는 만큼).
  5. FBX(또는 GLB)로 내려받습니다. 텍스처가 함께 들어 있습니다.

3Blender로 정리하기

Tripo 결과는 크기, 방향, 원점(피벗)이 제각각이고 면 수가 많습니다. 아래 순서대로 정리합니다. 부품 하나씩 따로 합니다.

3-1. 불러오기

  • File → Import → FBX(또는 glTF). 화면 오른쪽 위 Overlays → Statistics를 켜서 삼각형 수를 봅니다.

3-2. 면 수 줄이기

  • 오브젝트 선택 → Modifier 추가 → Decimate → Ratio를 낮춰 위 표의 목표 삼각형 수에 맞춥니다.
  • 모양이 무너지기 직전까지만 줄입니다. 각진 로우폴리 느낌이 나면 오히려 좋습니다.
  • Modifier 드롭다운 → Apply.

3-3. 크기와 방향

  • Blender 기본 단위(미터)로 몸통 높이 약 1.6m가 되게 키웁니다(N 키 → Dimensions의 Z 확인).
  • 정면 보기(넘패드 1)에서 얼굴 쪽이 보이게 돌립니다.
  • 방향이 조금 틀어져도 괜찮습니다. 언리얼 쪽 데이터에서 회전을 보정할 수 있습니다.

3-4. 원점(피벗) 맞추기

부품원점 위치하는 법
몸통바닥 중앙메시를 옮겨 바닥이 Z=0에 닿고 가운데가 X=0, Y=0에 오게 → Object → Set Origin → Origin to 3D Cursor(커서는 Shift+C로 원점)
투구머리에 씌워지는 안쪽 중심투구 안쪽 가운데를 0,0,0에 맞추고 같은 방법
손손 중심Object → Set Origin → Origin to Geometry → 위치를 0,0,0으로

3-5. 팀 색 영역 (선택이지만 추천)

  • 레드/블루 팀 색을 게임에서 칠하려면 그 부분이 다른 머티리얼 슬롯이어야 합니다.
  • 편집 모드(Tab) → 팀 색으로 칠할 면 선택(예: 투구 깃털, 목도리, 옷 띠) → Material 탭에서 슬롯 추가 → 이름 TeamColor → Assign.
  • 나머지 면은 첫 번째 슬롯(텍스처)에 그대로 둡니다.

3-6. 얼굴 자리

  • 얼굴이 들어갈 자리는 매끈하게 두기만 하면 됩니다. 판은 제가 언리얼에서 붙입니다.
  • Tripo가 얼굴을 조금 만들어 버렸다면 편집 모드에서 그 면들을 선택해 Smooth Vertices(또는 Sculpt의 Smooth 브러시)로 평평하게 해 주세요.

3-7. 마무리와 내보내기

  • 오브젝트 모드에서 Ctrl+A → All Transforms(크기·회전 적용).
  • File → Export → FBX: Limit to Selected Objects, Object Types는 Mesh만, Geometry의 Smoothing은 Face, Apply Modifiers 켬, Path Mode는 Copy(텍스처 같이 저장, 옆의 상자 아이콘 켬).
  • 부품마다 따로 내보냅니다: 몸통, 투구, 손.
