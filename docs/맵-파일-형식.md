# 블럭 맵 파일 형식 (AI 작성용)

맵은 블럭을 하나씩 찍지 않고 **구조물 단위 명령**으로 쓴다. 파일은 `Content/MapData/<이름>.json`.
맵 제작 모드에서 파일을 저장하면 1초 안에 다시 불러온다 (핫 리로드). 경고는 Output Log `LogCRBlockArena`와 화면 왼쪽 위에 나온다.

## 좌표

- 블럭 하나 = 50cm. 칸 좌표 `[x, y]`는 0부터 `size - 1`까지 (맵 가운데가 월드 원점)
- 구조물 높이 `z`는 지면 바로 위가 0
- 지면 맨 위가 월드 z = 0. 플레이어 시작점은 맵 가운데라서 가운데 근처는 비워 두는 것이 좋다

## 맨 위 필드

| 필드 | 기본값 | 설명 |
|---|---|---|
| `name` | 파일 이름 | 표시용 |
| `size` | `[64, 64]` | 가로, 세로 칸 수 (4 ~ 256) |
| `height` | `14` | 지면 위 구조물 공간 층 수 |
| `ground` | `["grass", "dirt", "dirt", "stone"]` | 지면 층, 위에서 아래 순서. 개수가 지면 두께 |
| `structures` | `[]` | 아래 명령 목록. 뒤에 쓴 명령이 앞을 덮어쓴다 |

## 블럭 (`block`)

| 이름 | HP | 비고 |
|---|---|---|
| `grass` | 2 | |
| `dirt` | 2 | |
| `stone` | 4 | 기본값 |
| `brick` | 3 | |
| `wood` | 2 | |
| `crystal` | 1 | 발광, 가끔 반짝임 |

## 명령 (`type`)

| type | 필드 | 설명 |
|---|---|---|
| `wall` | `from`, `to`, `height`(5), `thickness`(1), `gate`{`at`, `width`, `height`}, `battlements`(false) | 성벽. 대각선도 계단처럼 이어짐. `gate.at`은 from에서 몇 번째 칸 |
| `tower` | `at`, `radius`(3), `height`(10), `hollow`(true), `door`(true) | 원형 탑. 꼭대기 총안, +X 쪽 문 |
| `pyramid` | `at`(중심), `base`(9) | 계단식 피라미드 |
| `bridge` | `from`, `to`, `height`(4), `width`(2) | 상판 + 양 끝 기둥. 기둥이 부서지면 상판이 무너진다 |
| `box` | `at`(모서리), `size`[x, y, z], `z`(0) | 직육면체 |
| `pillar` | `at`, `height`(4) | 기둥 |
| `fill` | `from`[x, y, z], `to`[x, y, z] | 직육면체 채우기 (z 음수 = 지면 층) |
| `hole` | `from`[x, y], `to`[x, y], `depth`(지면 전체) | 지면 파기. 지면 두께만큼 파면 허공 (떨어지면 죽음) |

## 동작 규칙

- 땅에 닿은 구조물에서 6방향으로 연결이 끊긴 블럭은 떨어진다 (아치, 다리 상판은 양쪽이 붙어 있으면 버팀)
- 부서진 블럭은 6초 + 랜덤 + 층 × 0.15초 뒤 아래부터 다시 자란다 (튜닝 "블럭 지형" 탭)
- 무기: 레이저·투사체 1, 번개 3, 펀치 2, 미사일은 반경 110 크레이터
