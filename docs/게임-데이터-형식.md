# 게임 데이터 파일 형식 (Content/GameData/*.json)

게임이 런타임에 직접 읽는다 (DataTable 임포트 없음). 에디터·개발 빌드에서는 1초마다 파일 시각을 확인해 바뀌면 다시 읽는다 (Shipping은 감시하지 않음). 패키징은 `DirectoriesToAlwaysStageAsNonUFS=GameData`.

폴더 안의 모든 `.json`을 읽고, 아래 최상위 키를 파일 구분 없이 합친다. 잘못된 항목은 무시하고 로그(`GameData: ...`)에 파일·키 이름을 남긴다.

## tuning: 튜닝 기본값

```json
{ "tuning": { "Sword": { "Damage": 25, "Length": 90 }, "Raw": { "MaxHealth": 1000 } } }
```

- 항목 이름 = 섹션 + 키 (`Sword` + `Damage` → `SwordDamage`). `Raw`는 키를 이름 그대로 쓴다.
- 이름은 `UCRTuningSettings` 멤버 (옵션창 항목). 없는 이름은 경고.
- 옵션창에서 바꾼 값(SaveGame)이 JSON 기본값보다 우선한다. 저장은 "JSON 기본값과 다른 값만", "이 탭만 기본값"은 JSON 기본값으로 되돌린다.
- 지금 파일: `weapons.json` (무기·패시브 기본형), `characters.json` (캐릭터 스탯).

## upgrades: 로그라이크 업그레이드

```json
{ "upgrades": [
  { "id": "gun_shotgun", "skill": "active.gun", "name": "산탄총", "desc": "한 번에 5발", "max": 1,
    "requires": "gun_rate",
    "mods": [ { "stat": "Count", "add": 4 }, { "stat": "Damage", "mul": 0.6 } ] }
] }
```

| 필드 | 뜻 |
|---|---|
| `id` | 고유 이름 (콘솔 `CRUpgrade <id> [단계]`) |
| `skill` | 대상 스킬 = 형태.계열. 형태 `active` / `passive`, 계열 `sword` `laser` `gun` `lightning` `launcher` `flame` `punch` |
| `max` | 최대 단계 (1~20) |
| `requires` | 이 업그레이드가 1단계 이상이어야 올릴 수 있음 (선택) |
| `mods` | 단계마다 적용. 값 = (기본 + add × 단계) × mul^단계 |

스탯 (`stat`): `Damage` `Interval`(액티브 간격 / 패시브 쿨다운) `Knockback` `Range` `Count`(산탄 탄 수, 레이저 줄기, 런처 발 수, 오비탈 칼날, 불 칸) `Spread` `Pierce` `Size` `Radius` `Length` `Arc` `SwingTime` `Speed` `Crater` `Chain` `ChainRange` `DotDamage` `DotTime` `Homing`(0/1) `Salvo`(0/1) `Dual`(0/1)

## helmets: 투구 (지금은 외형만)

```json
{ "helmets": [ { "id": "helmet.knight", "name": "투구", "shape": "knight", "color": [0.55, 0.58, 0.65] } ] }
```

`shape`: `cap`(기본 모자) / `knight`(둥근 투구) / `crown`(왕관). `helmet.cap`은 투구를 벗었을 때 쓰는 기본값이라 지우지 않는다.

## blocks: 블럭 표

```json
{ "blocks": { "stone": { "health": 4, "color": [0.52, 0.53, 0.58] } } }
```

블럭 이름은 맵 파일과 같다 (`grass` `dirt` `stone` `brick` `wood` `crystal`). HP 1~255. 새로 불러오는 맵부터 적용.
